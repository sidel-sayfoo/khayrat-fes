# Khayrat Fes - Application Mobile de Gestion de Syndic

Application mobile pour la gestion de syndic résidentiel au Maroc.

## Fonctionnalités

- 📱 Tableau de bord pour syndics
- 👥 Gestion des résidents et copropriétaires
- 💰 Gestion des paiements et charges
- 🔧 Suivi des réclamations et maintenance
- 📊 Rapports et statistiques
- 🔔 Notifications et alertes

## Technologies

- React Native avec Expo
- TypeScript
- NativeWind (Tailwind CSS pour React Native)
- Expo Router pour la navigation
- Composants UI inspirés de shadcn/ui

## Installation

```bash
npm install
```

## Démarrage

```bash
npm start
```

## Build

```bash
# Android
npm run android

# iOS
npm run ios
```
