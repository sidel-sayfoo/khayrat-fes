# 📱 Tester l'application avec Expo Snack (Sans ordinateur)

## Option 1 : Accéder à un Snack pré-configuré

1. Sur votre smartphone, ouvrez un navigateur
2. Allez sur : **https://snack.expo.dev**
3. Créez un nouveau Snack
4. Copiez-collez le code de l'application

## Option 2 : Créer un Snack depuis le code

Voici les étapes pour créer un Snack avec l'application :

### 1. Ouvrir Expo Snack
Allez sur https://snack.expo.dev dans votre navigateur

### 2. Créer un nouveau projet
- Cliquez sur "Create new Snack"
- Choisissez un nom pour votre projet

### 3. Installer les dépendances
Dans le panneau de gauche, cliquez sur "Dependencies" et ajoutez :
- `expo-router`
- `nativewind`
- `lucide-react-native`
- `react-native-safe-area-context`
- `react-native-screens`

### 4. Copier les fichiers
Vous devrez copier les fichiers principaux de votre projet dans Snack.

### 5. Scanner le QR code
Une fois le Snack configuré, scannez le QR code avec Expo Go !

## Limites d'Expo Snack

- Certaines fonctionnalités avancées peuvent ne pas fonctionner
- La performance peut être légèrement réduite
- Toutes les dépendances ne sont pas disponibles

## Alternative : Attendre d'avoir un ordinateur

Pour la meilleure expérience, il est recommandé d'attendre d'avoir accès à un ordinateur pour :
- Installer toutes les dépendances
- Tester l'application complète
- Avoir une meilleure performance

Une fois que vous aurez un ordinateur :
1. Consultez le [QUICKSTART.md](./QUICKSTART.md)
2. Lancez `npm install && npm start`
3. Scannez le QR code avec Expo Go
